# Zion Kids Website Prototype

Open `index.html` in a web browser to view the prototype.

This is the first visual/interactive prototype. It is not yet a production website:
- No real login/authentication
- No database
- No secure child records
- No real email/SMS notifications
- No real cloud deployment

Recommended next build:
1. Secure teacher/leader accounts and permissions
2. Database for classes, teachers, children, attendance, reports, and announcements
3. Real Saturday daily-report submission
4. Leader "All Reports" filters and export
5. Secure incident-report access
6. Parent portal and child check-in/check-out
